API Documentation

This guide details how to consume the Gateway from a mobile or web frontend, and outlines the strict B2B contract required for external microservices to join the Super App ecosystem.

1 Architecture Overview

The Tawi-Tawi Gateway acts as the central brain. It handles public user authentication (including Google and Meta identity providers) and securely routes authenticated user data to specialized internal microservices via Server-to-Server handshakes.

  • API Protocol: GraphQL
  • Primary Endpoint: POST /graphql
  • Database: Neo4j (Graph Database)
  • Authentication: Stateless JWT (JSON Web Tokens)

2 Local Environment Setup

To run the Gateway locally, ensure Node.js (v18+) is installed. Create a .env file in the root directory with the following configuration:

# --- Server Configuration ---
PORT=1738
NODE_ENV=development

# --- Neo4j Database ---
NEO4J_URI=bolt://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=secure_password

# --- Authentication & Identity ---
JWT_SECRET=long_random_string
GOOGLE_CLIENT_ID=your_google_client_id.apps.googleusercontent.com
META_APP_ID=your_meta_app_id
META_APP_SECRET=your_meta_app_secret

# --- B2B Microservices Handshake ---
GATEWAY_INTERNAL_SECRET=secure_shared_secret_key
TOURISM_SERVICE_URL=http://localhost:3001
TRANSPORT_SERVICE_URL=http://localhost:3002

Frontend Integration Guide

How mobile (Flutter/Kotlin) and web apps communicate with the Gateway.

Authentication Headers

Once a user logs in, the Gateway issues a JWT. This token must be included in the HTTP headers of all subsequent requests to access protected queries.

Authorization: Bearer <YOUR_JWT_TOKEN>

Core GraphQL Operations

Standard Registration
mutation RegisterUser {
  register(
    fullName: "Juan Dela Cruz", 
    email: "juan@example.com", 
    password: "SecurePassword123!"
  ) {
    token
    user {
      id
      fullName
      email
    }
  }
}
Social Login (Google / Meta)
The client application must use the official Google/Meta SDKs to obtain an ID token, which is then passed to the Gateway for server-side validation.
mutation LoginWithGoogle {
  googleLogin(idToken: "TOKEN_FROM_MOBILE_SDK") {
    token
    user {
      id
      email
    }
  }
}

Microservice Integration Guide

The strict API contract required for external services to join the ecosystem.

The Security Architecture

The Gateway does not store specialized data. It acts as an identity provider. All communication between the Gateway and external microservices is secured using a pre-shared key. The Gateway sends the X-Internal-Gateway-Secret header with every request. The external microservice must validate this header before processing the payload.

1. The Verification Endpoint

The Gateway calls this endpoint when a user attempts to access the microservice. The microservice must expose POST /verify-user.

Gateway Request Payload 
{
  "tawiTawiUserId": "uuid-string",
  "email": "user@example.com",
  "fullName": "Juan Dela Cruz"
}
Expected Microservice Response
{
  "isLinked": true, 
  "requiresRegistration": false,
  "externalUserId": "local-db-id-123"
}

2. The Registration Endpoint

If verification fails, the Gateway can register the user directly. The microservice must expose POST /register-user.

Gateway Request Payload
{
  "tawiTawiUserId": "uuid-string",
  "email": "user@example.com",
  "fullName": "Juan Dela Cruz",
  // Extra fields sent from the frontend UI
  "phoneNumber": "09123456789"
}
Expected Microservice Response
{
  "isLinked": true
}

3. Implementation Examples

Starter templates to quickly integrate an external microservice with the Gateway.

Node.js (Express) 
const express = require('express');
const app = express();

app.use(express.json());

// Middleware to verify the Gateway Signature
function requireGatewayAuth(req, res, next) {
  const secret = req.headers['x-internal-gateway-secret'];
  
  if (secret !== process.env.GATEWAY_INTERNAL_SECRET) {
    return res.status(401).json({ success: false, message: "Unauthorized" });
  }
  next();
}

// Handshake: Verification
app.post('/verify-user', requireGatewayAuth, async (req, res) => {
  const { tawiTawiUserId, email } = req.body;
  
  // Query the local database to check if the user exists
  const userExists = true; 
  
  if (userExists) {
    res.json({ isLinked: true, requiresRegistration: false, externalUserId: "123" });
  } else {
    res.json({ isLinked: false, requiresRegistration: true, externalUserId: null });
  }
});

// Handshake: Registration
app.post('/register-user', requireGatewayAuth, async (req, res) => {
  const { tawiTawiUserId, email, fullName } = req.body;
  
  // Insert the user into the local database
  res.json({ isLinked: true });
});
